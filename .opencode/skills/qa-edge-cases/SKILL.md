# 🛠️ Skill: QA Edge-Case Checklist

Whenever you are assigned to a testing task, always write test cases addressing the following scenarios:

1. **Empty Inputs**: How does the function handle empty arrays `[]`, empty strings `""`, or empty objects `{}`?
2. **Missing Parameters**: What happens if the function is executed with fewer parameters than expected?
3. **Data Types**: Does the function degrade gracefully or throw a clear error when receiving `null` or `undefined`?
4. **Duplications**: Does the algorithm handle duplicate dataset items seamlessly without infinite loops or memory spikes?
