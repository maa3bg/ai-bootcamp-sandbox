# Stakeholder requests (as they arrived)

> Sandbox data for the Product Owner exercises. Each request is deliberately vague.

## REQ-1: Role coverage (from: Team Lead, via chat)
> "Our team leads want to know quickly which roles are covered this week. Make it so we can see who is available
> per role, and warn us when a role has nobody. Should be easy to use."

## REQ-2: Hours report (from: Finance, via email)
> "We need the hours per person for invoicing. Monthly is fine, but weekly would be better. Don't count the
> weird rows."

## REQ-3: Board hygiene (from: Delivery Manager, in the retro)
> "The board lies. Cards say Done when they are not. Can the agents keep it honest?"
